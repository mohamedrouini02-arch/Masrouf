# Masrouf

Personal money tracker for a freelancer in Algeria. Income, expenses, debts, savings pots and multi-currency accounts (DZD, USD, EUR, KRW, CNY, GBP), all totalled in dinars.

Installable web app (PWA). No build step, no server: plain HTML, CSS and JS. Data stays on the device in browser storage, with export and restore of a JSON backup and CSV export from Settings.

## Deploy

Static site. On Vercel, import this repo with Framework Preset "Other" and no build command. `vercel.json` sets no-cache headers so updates reach phones.

## Install on Android

Open the site in Chrome → menu ⋮ → Add to Home screen → Install.
